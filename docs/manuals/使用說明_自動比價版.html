申請帳號

開啟 app.yintsun66.com → 填分行名稱、五碼行編、密碼 → 由 ADMIN／PS 審核 → 核准後以五碼行編登入。既有帳號沿用原登入名稱。

操作流程

1. 輸入條件　欄位與靜態版相同（Product、Currency、BBG Code 1–5、Tenor、Guaranteed Periods、Strike、KO Type、KO Barrier、Coupon、Upfront、Barrier Type、KI Barrier）。固定值欄位不需填寫。手機／平板有交易導覽列可跳至第 N 筆，固定值自動隱藏，送出內容不變。

2. 勾選發行機構　畫面顯示選取家數與實際寄出封數。BNP、MS、JPM、BARCLAYS 共用格式合併為一封。

只有勾選的機構會進入比價。四家共用一封信，未勾選者仍可能回信，該回覆僅供稽核，不會進入排名、自選第五名或報價圖。漏勾等於沒詢到。

3. 建立並寄送　按送出後系統一次完成建立、驗證與寄送，不需再按其他按鈕。

4. 等待與暫定排名　時程：7 分暫定提醒 → 15 分機構回覆期 → ＋60 秒郵件轉送緩衝 → 最晚 16 分建立正式排名。

  • 回覆期間顯示暫定前四名與候選，仍會變動，不建立正式排名，也不能產報價圖。
  • 最後 60 秒顯示「正在等待最後郵件轉送」，此期間不可提早結束。
  • 勾選 3 家以內：若每筆都已有足夠有效報價，7 分鐘後畫面提示可提早結束，確認視窗會列出尚未回覆的機構。提早結束由你決定，系統不會自動縮短。

5. 正式結果

  • 自動顯示經濟排名前四名；第五名由你自選（從前四名以外的有效機構挑一家）。
  • 按機構旁「產出報價圖」產生 PNG，先顯示預覽：電腦另開頁面存檔，手機／平板長按圖片儲存。前四名與自選第五名皆可。
  • 晚到報價不改動已成立的排名。需納入時按「納入晚到報價重新排名」建立新版本，舊版本永久保留。
  • 我的詢價：可回到任何進行中或已完成的詢價，關掉瀏覽器不會遺失。

市場與風險分析

正式排名的前四名或自選第五名可另開此頁：顯示該標的 SEC 公司與最近申報文件；「輸入標的參考現價」空白時自動帶入前一個已收盤美股交易日的收盤價，並標示來源與日期。參考現價只存在你的瀏覽器，不影響排名、寄件與報價圖。帶入的是前一交易日收盤價，不是即時報價，僅供試算；需要當下價格請自行確認後手動覆蓋。

跟單專區

  • 獨立頁面，訪客不需註冊，輸入管理者提供的四位數檢視密碼即可查看。
  • 商品由授權信箱回覆詢價信後自動上架，到期自動下架並保留稽核資料。
  • 公開表格行編一律遮蔽，完整明細限 ADMIN／PS 於後端查看。可登記預計跟單金額並查看當日彙整。
  • 日股不可跟單、不可湊單，請勿放上跟單專區。
  • CLN 跟單：PS 須逐筆填製交易確認給信託處。

手動貼郵件詢價：自動寄信不便時可改用複製貼上流程，不影響後端自動收單。
