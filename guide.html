FCN / DAC 詢價系統使用說明

本頁僅說明系統操作：詢價條件的填寫方式、價格求值規則，以及兩種使用模式的流程。 交易規範請依信託處公告及內部書面說明辦理，本頁不涉及。

兩種使用模式

項目靜態版自動比價版
是否需要登入不需要需要（五碼行編）
資料存放只留在本機瀏覽器伺服器保存，可跨裝置回到「我的詢價」
寄送方式複製表格後自行以郵件程式寄出系統自動寄送與收單
比價排名無自動排名，前四名加自選第五名
跟單專區可檢視（需四位數密碼）可檢視（需四位數密碼）

兩種模式的條件輸入方式與欄位規則完全相同，差別只在寄送與比價。

快速操作：靜態版

  1. 在表格第一列輸入一筆交易條件。
  2. 需要多筆詢價時點選「新增一筆交易」，最多 20 筆；新列會複製第 1 筆，可再個別修改。
  3. 點選「發送詢價條件」進行驗證，再選擇詢價對象。
  4. 系統依詢價對象建立對應主旨與欄位順序的 HTML 表格並先複製到剪貼簿。手機或已設定郵件程式的電腦可選「使用裝置預設郵件程式」；已在同一瀏覽器登入 Zimbra 者，可貼上一次 Zimbra 網址後選「開啟 Zimbra 新郵件」。
  5. 開啟郵件後在本文貼上已複製的表格並自行寄出。系統無法讀取 Zimbra 登入資料，也不會代替使用者按下寄出；Zimbra 網址只保存在目前瀏覽器。
  6. 選擇多家時，完成目前郵件後回到本頁按「這封已完成，準備下一封」，系統會依序準備各封郵件，全部完成後按「結束流程」。
  7. 點選「產出報價圖」，選擇發行機構後即可下載 PNG 報價卡；發行機構只會顯示在圖片，不會寫入詢價郵件。

快速操作：自動比價版

  1. 以五碼行編登入。首次使用請先申請帳號（填分行名稱、五碼行編、密碼），待管理者核准。
  2. 輸入交易條件，方式與靜態版相同。
  3. 勾選要詢價的發行機構。畫面會顯示選取家數與實際寄出封數；BNP、MS、JPM、巴克萊共用同一種郵件格式，會合併為一封信寄出。
  4. 送出後系統一次完成建立、驗證與寄送，直接進入詢價流程。
  5. 回覆期間可看到暫定排名，數值仍會變動，不會建立正式排名，也不能產報價圖。
  6. 回覆期結束後建立正式排名：自動顯示前四名，第五名由使用者從其餘有效機構自選。
  7. 在發行機構旁點選「產出報價圖」；圖片在自己的瀏覽器產生，會先顯示預覽，電腦可另開頁面存檔，手機或平板長按圖片儲存。
  • 只有勾選的機構會進入比價。由於部分機構共用同一封信，未勾選者仍可能回信，這類回覆會保留供稽核，但不會進入暫定排名、正式排名、自選第五名或報價圖。想比價的機構務必勾選。
  • 晚到的報價不會改動已成立的排名；需要納入時可建立新的排名版本，舊版本永久保留。
  • 正式排名的前四名或自選第五名，可另開「市場與風險分析」頁。該頁的參考現價欄位若留空，會自動帶入前一個已收盤美股交易日的收盤價（非即時報價），並標示資料來源與日期；此數值只存在目前瀏覽器，不會改變排名、寄件內容或報價圖。

手機與平板

  • 畫面上方會出現「交易導覽列」，可直接跳到第 N 筆交易。
  • 固定值欄位（Observation Frequency、OTC、Effective Date Offset、Trade Date）會自動隱藏以縮短畫面，但送出的內容完全不變。

欄位說明

欄位填寫規則
Product選擇 FCN 或 DAC；系統會依詢價對象自動換成該家接受的商品代碼。
Currency預設 USD；可選 JPY、EUR、HKD、CNH、CAD、GBP、AUD、NZD、ZAR。
Guaranteed Periods (m)預設 1；最小為 1，且不得大於 Tenor。
BBG Code 1–5至少填一個，最多五個。輸入美股 ticker 後離開欄位，系統會依交易所檔案自動補上交易所代碼。
Strike (%)可留白求值；若填寫，數值須介於 50 至 100。
KO Type預設 Daily Memory；可選 Daily、Daily Memory、Period End、Period End Memory。Memory 表示含記憶功能。
KO Barrier (%)、Coupon p.a. (%)可留白求值。
Upfront / NotePrice (%)預設 98；可留白求值。
Tenor (m)必填，範圍為 1 至 24。
Barrier Type預設 NONE；可選 EKI、AKI、NONE。當 KI Barrier 大於 0 時，不得選 NONE。
KI Barrier (%)可留白求值；Barrier Type 為 NONE 時必須留白。
Observation Frequency (m)固定為 1。
OTC固定為 Note。
Effective Date Offset固定為 7 個 Calendar Days。
Trade Date預設為今天，可調整；格式為 DD-MMM-YY，例如 15-Jul-26。
詢價對象（寄信時選擇）可選 BNP MS JPM 巴克萊、Nomura、UBS、DBS、SG、CITI、GS、CA。每個對象會使用其模板的欄位順序與產品代碼。
發行機構（產圖時選擇）可選 BNP、BARCLAYS、MS（OBU 不得承做）、JPM、Nomura、UBS、DBS、SG、CITI、GS、CA；僅影響報價圖的品牌、配色與發行機構標示。

價格求值規則

  • Barrier Type 為 EKI 或 AKI 時：Strike、KO Barrier、Coupon、Upfront / NotePrice、KI Barrier 五欄必須且只能留一欄空白。
  • Barrier Type 為 NONE 時：KI Barrier 必須空白；Strike、KO Barrier、Coupon、Upfront / NotePrice 四欄必須且只能留一欄空白。
