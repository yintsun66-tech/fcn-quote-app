操作流程

STEP 1輸入 1–20 筆條件
STEP 2選發行機構
STEP 3複製詢價表格
STEP 4貼上並寄出
STEP 5逐家完成

1. 輸入條件　「＋ 新增一筆交易」最多 20 筆。輸入會自動存在本機，關掉再開仍在；「清除本機暫存」可清空。

欄位填法
Product｜CurrencyFCN 或 DAC（系統自動換成各家接受的代碼）｜USD、EUR、JPY、AUD、CNH、ZAR、GBP、NZD、CAD、HKD
BBG Code 1–51–5 檔。輸入 AAPL 自動補為 AAPL UW。中概股不得輸入。
Tenor (m)｜Guaranteed Periods (m)期間月數 1–24｜保證配息期數；填 1 表示第一期不會被 KO 帶走
Strike (%)轉換價格 50–100。> 85% 需先陳核分行經理
KO Type｜KO Barrier (%)Period End／Daily／Daily Memory／Period End Memory（Memory 為含記憶）｜提前出場價
Coupon p.a. (%)｜Upfront / NotePrice (%)兩者擇一留空由機構報價。填 98 約等於手收 2%
Barrier Type｜KI Barrier (%)EKI 到期觀察／AKI 存續觀察／NONE 無保護｜選 NONE 時 KI 必須留空
不必填：Observation Frequency＝1、OTC＝Note、Effective Date Offset＝7、Trade Date 自動帶當日。
手機／平板：上方有交易導覽列可跳至第 N 筆，固定值欄位自動隱藏，送出內容不變。

2. 選發行機構　按「變更發行機構」勾選。BNP、MS、JPM、BARCLAYS 共用格式合併為一封；NOMURA、UBS、DBS、SG、CITI、GS、CA 各自一封。

3–5. 複製、貼上、寄出　按「發送詢價條件」複製表格 → 選「使用裝置預設郵件程式」或「開啟 Zimbra 新郵件」→ 在信中貼上並自行按寄出 → 按「這封已完成，準備下一封」重複 → 全部寄完按「結束流程」。

本工具不會替你寄信。靜態版只產生格式正確的表格，寄出一律由你在郵件程式完成。格式跑掉請按「重新複製詢價表格」。Zimbra 網址只存在你的瀏覽器，不會上傳。

其他

  • 產出報價圖：將目前條件產成 PNG 供對客說明，圖片在你的裝置產生。
  • 載入即時熱門榜：首頁美股／日股熱門榜，需勾選同意才載入。
  • CLN 跟單：PS 須逐筆填製交易確認給信託處。
  • 靜態版無自動比價、自動收單與跟單專區，需要請改用自動比價版。
